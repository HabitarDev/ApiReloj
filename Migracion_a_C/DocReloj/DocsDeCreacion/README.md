# Archivo histórico de diseño

Los documentos de esta carpeta registran planes, diagnósticos y contratos provisionales utilizados durante la construcción de ApiReloj.

No constituyen la especificación vigente. Pueden contener clases de ejemplo, rutas futuras nunca implementadas, Compose anteriores y mecanismos de seguridad reemplazados.

Fuentes actuales:

- contrato externo: `../DocParaImplementadores/`;
- seguridad: `../seguridad_endpoints.md`;
- instalación: `../guia_instalacion_windows10_api_reloj.md`;
- referencia ISAPI: `../isapi_summary.md`.

Se conserva el contenido original para explicar decisiones y facilitar investigación de regresiones.
